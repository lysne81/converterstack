# ConverterStack

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://github.com/lysne81/converterstack/blob/main/LICENSE)

ConverterStack is a fast, free, no-fuss converter for units, exchange rates,
time zones and files, built with [Next.js](https://nextjs.org). Most
conversions run entirely in the browser.

- **Repository:** https://github.com/lysne81/converterstack
- **Issues / feature requests:** https://github.com/lysne81/converterstack/issues
- **License:** [MIT](./LICENSE)

## Getting Started

Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
